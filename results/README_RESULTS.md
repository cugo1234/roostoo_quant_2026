# Results directory

- `candidate_strategies.csv`: exact candidate definitions and intended use.
- `teammate_sample_diagnostics.json`: real supplied BTC/ETH sample audit.
- `synthetic_smoke/`: deterministic software-only smoke test. Do not use its P&L as evidence.
- `research_status.json`: what is and is not empirically complete.
- `full_research/`: created by `scripts/run_full_research.py` after Binance history is downloaded.
